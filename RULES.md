# VIVARTHA Project Rules

These rules apply to every task performed in this project.

1. Update the relevant project documents after every change in code.
2. If everything works, push the changes to GitHub.
3. Create a report for the current work or task.
4. If anything fails, clearly state:
   - what failed;
   - why it failed; and
   - the failure category: `partial`, `failed`, or `conditional`.
5. Every report must include a final verdict using one of these labels:
   - `PASS`
   - `CONDITIONAL PASS`
   - `FAILED`

## Task-start requirement

Read and follow this file before starting every task in this project, including tasks resumed in a new chat or context window.

## Reporting requirement

Each completed task must report:

- the work performed;
- files changed;
- tests or verification performed;
- any failures and their causes;
- whether changes were pushed to GitHub; and
- the final verdict.
